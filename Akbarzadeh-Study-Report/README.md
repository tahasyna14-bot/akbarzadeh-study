# آکادمی اکبر زاده — سامانه گزارش مطالعه

این نسخه عمداً از فروش دوره، فروشگاه، پرداخت، آزمون و بخش‌های تبلیغاتی حذف شده و تمرکز آن فقط روی گزارش مطالعه و رقابت است.

## امکانات
- ثبت گزارش روزانه
- تاریخ خودکار شمسی و غیرقابل ویرایش
- افزودن چند درس در یک گزارش
- انتخاب نام درس
- اسلایدر ساعت مطالعه
- اسلایدر تعداد تست
- اسلایدر بازدهی
- توضیحات برای هر درس
- افزودن/حذف درس
- داشبورد هفتگی
- نمودار هفت روز اخیر
- سوابق و مشاهده جزئیات هر گزارش
- جدول رقابت هفتگی
- پروفایل با نام، نام خانوادگی، پایه، رشته، درباره من و تصویر
- حالت روشن/تیره بسیار ساده
- چاپ سوابق
- ذخیره اطلاعات در localStorage

## اجرا
پوشه را در VS Code باز کنید و `index.html` را با Live Server اجرا کنید.

## الهام معماری
ساختار کلی داشبورد از الگوهای رایج پروژه‌های Vanilla JS در GitHub الهام گرفته شده، اما UI و منطق این پروژه اختصاصی است.
